devl-ui.

Componentes propios sin dependencias con el mismo lenguaje visual de devl.dev: tokens en CSS, HTML semántico y Custom Elements en light DOM. Copia el HTML de cualquier demo, enlaza dos archivos y funciona en cualquier proyecto (estático, SSR o framework).

Empezar devl-ui.css devl-ui.js

Instalación

Copia la carpeta lib/ a tu proyecto. El CSS funciona solo; el JS añade interactividad (Custom Elements y atributos data-dv-*). Pon la clase dv en <body> para heredar fuente y colores. Tema oscuro por defecto; data-theme="light" en <html> para claro.

<link rel="stylesheet" href="lib/devl-ui.css" />
<script src="lib/devl-ui.js" defer></script>

Tokens

Todo el estilo sale de variables --dv-*. Sobrescríbelas después de cargar devl-ui.css para adaptar la marca (o usa el panel lateral y "Copiar overrides CSS").

Tipografía

Mono por defecto, sans para titulares. Utilidades: dv-eyebrow, dv-heading, dv-muted, dv-kbd.

Button

Variantes --primary, --accent, --subtle, --danger; tamaños --sm, --lg, --icon, --block, --pill. aria-busy="true" muestra un spinner.

Button group

Une botones adyacentes en un solo control.

Dropdown menu

<dv-menu> con navegación por teclado (↑ ↓ Home End Esc), cierre al hacer clic fuera y evento dv-select. align="end" lo alinea a la derecha.

Chip / toggle

Chips de filtro. Con data-dv-toggle alternan aria-pressed y emiten dv-change.

Copy button

data-dv-copy="texto" copia un valor fijo; data-dv-copy-target="#id" copia el contenido de otro elemento.

Input & field

dv-field agrupa dv-label, control, dv-hint y dv-error. Usa aria-invalid="true" para el estado de error.

Input group

Añade prefijos/sufijos con dv-input-group__addon.

Select & textarea

Controles nativos con el estilo de la biblioteca.

Checkbox & radio

<input type="checkbox|radio" class="dv-check">, envuelto en dv-choice para la etiqueta. Soporta indeterminate.

Switch

Checkbox nativo con role="switch": accesible y compatible con formularios.

Range slider

Relleno de color automático. data-dv-output="#id" muestra el valor; data-dv-suffix añade unidad.

Number stepper

Botones con data-step="-1|1" que respetan min, max y step del input.

Segmented control

<dv-segmented value="…"> con role="radiogroup", flechas ← → y evento dv-change.

OTP input

<dv-otp length="6" name="code">: avance automático, retroceso, pegado y evento dv-complete. mode="text" acepta letras.

Tag input

<dv-tags>: Enter o coma para añadir, Retroceso para borrar. Atributos value, name, max, placeholder.

Dropzone

<dv-dropzone accept multiple name>: arrastrar o hacer clic; lista los archivos y emite dv-change con files.

Calendar

<dv-calendar value="YYYY-MM-DD"> con nombres localizados (locale, por defecto el lang del documento), week-start y navegación con flechas.

Tabs

<dv-tabs> enlaza data-tab con data-panel y añade los roles ARIA y la navegación con flechas.

Breadcrumb

Lista ordenada con separadores automáticos; marca la página actual con aria-current="page".

Pagination

Enlaces o botones; la página activa usa aria-current="page".

Sidebar nav

Navegación vertical para app shells: dv-nav, dv-nav__label, dv-nav__item.

Steps

Progreso por pasos: data-state="done" y aria-current="step".

Command palette

<dv-command hotkey="k"> crea un <dialog> nativo con búsqueda difusa, grupos (data-group), palabras clave (data-keywords) y evento dv-select. Ábrelo con data-dv-open="id" o ⌘K.

Alert

Variantes --info, --success, --warning, --danger, --accent.

Banner

Barra de anuncio a ancho completo.

Toast

DevlUI.toast() apila notificaciones abajo a la derecha. Se pausan al pasar el ratón; duration: 0 las deja fijas; action añade un botón.

Progress & meter

<progress class="dv-progress"> nativo (sin value = indeterminado) y dv-meter por segmentos con --w y --c.

Spinner & skeleton

Estados de carga. Tamaño con --size (spinner) o --w/--h (skeleton).

Tooltip

Solo CSS: data-dv-tooltip="texto" y opcionalmente data-dv-placement="bottom". Aparece con hover y foco de teclado.

Dialog

<dialog class="dv-dialog"> nativo: atrapa el foco y cierra con Esc. data-dv-open="id" lo abre, data-dv-close lo cierra, clic en el fondo también (desactívalo con data-dv-static).

Drawer

Variante lateral del diálogo: añade dv-dialog--drawer.

Card

dv-card con __header, __body, __footer. --interactive añade elevación y spotlight que sigue al cursor.

Stat & sparkline

dv-stat para KPIs y <dv-sparkline values="…" fill> que dibuja un SVG con el color actual (cámbialo con color).

Badge & dot

Estados compactos. dv-dot--pulse anima un indicador en vivo.

Avatar

Iniciales o imagen, tamaños --sm/--lg, --square, estado con data-status="online|busy|away" y grupos solapados.

Table

Tabla con hover y números tabulares (is-num). Con data-dv-sortable y th[data-sort="text|number"] se ordena por clic o teclado.

List

Filas con título, descripción y acciones al final (dv-list__end).

Timeline

Historial vertical; colorea cada nodo con --c.

Empty state

Estado vacío con icono, título, descripción y acción.

Accordion

Basado en <details> nativo: accesible sin JS. Usa el mismo name en los details para que solo uno quede abierto.

Code block

dv-code sobre <pre>; añade un botón de copiar con data-dv-copy.

Divider

Separador con o sin etiqueta.

Layout helpers

dv-stack (vertical), dv-row (horizontal con wrap) y dv-grid (auto-fit). Ajusta con --gap y --min; dv-spacer empuja elementos.

Login

Ejemplo de composición: card + fields + divider + botones.

Settings panel

Tabs + lista + switches + acciones.
