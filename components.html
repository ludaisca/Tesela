devl-ui.

Componentes propios sin dependencias con el mismo lenguaje visual de devl.dev: tokens en CSS, HTML semántico y Custom Elements en light DOM. Copia el HTML de cualquier demo, enlaza dos archivos y funciona en cualquier proyecto (estático, SSR o framework).

Empezar devl-ui.css devl-ui.js

Instalación

Copia la carpeta lib/ a tu proyecto. El CSS funciona solo; el JS añade interactividad (Custom Elements y atributos data-dv-*). Pon la clase dv en <body> para heredar fuente y colores. Tema oscuro por defecto; data-theme="light" en <html> para claro.

<link rel="stylesheet" href="lib/devl-ui.css" />
<script src="lib/devl-ui.js" defer></script>

Tokens

Todo el estilo sale de variables --dv-*. Sobrescríbelas después de cargar devl-ui.css para adaptar la marca (o usa el panel lateral y "Copiar overrides CSS").

Tipografía

Mono por defecto, sans para titulares. Utilidades: dv-eyebrow, dv-heading, dv-muted, dv-kbd.

Botón

Variantes --primary, --accent, --subtle, --danger; tamaños --sm, --lg, --icon, --block, --pill. aria-busy="true" muestra un spinner.

Grupo de botones

Une botones adyacentes en un solo control.

Menú desplegable

<dv-menu> con navegación por teclado (↑ ↓ Home End Esc), cierre al hacer clic fuera y evento dv-select. align="end" lo alinea a la derecha.

Chip / interruptor

Chips de filtro. Con data-dv-toggle alternan aria-pressed y emiten dv-change.

Botón de copiar

data-dv-copy="texto" copia un valor fijo; data-dv-copy-target="#id" copia el contenido de otro elemento.

Input y campo

dv-field agrupa dv-label, control, dv-hint y dv-error. Usa aria-invalid="true" para el estado de error.

Grupo de inputs

Añade prefijos/sufijos con dv-input-group__addon.

Select y textarea

Controles nativos con el estilo de la biblioteca.

Casilla y radio

<input type="checkbox|radio" class="dv-check">, envuelto en dv-choice para la etiqueta. Soporta indeterminate.

Interruptor

Checkbox nativo con role="switch": accesible y compatible con formularios.

Control deslizante

Relleno de color automático. data-dv-output="#id" muestra el valor; data-dv-suffix añade unidad.

Selector numérico

Botones con data-step="-1|1" que respetan min, max y step del input.

Control segmentado

<dv-segmented value="…"> con role="radiogroup", flechas ← → y evento dv-change.

Campo OTP

<dv-otp length="6" name="code">: avance automático, retroceso, pegado y evento dv-complete. mode="text" acepta letras.

Campo de etiquetas

<dv-tags>: Enter o coma para añadir, Retroceso para borrar. Atributos value, name, max, placeholder.

Zona de carga

<dv-dropzone accept multiple name>: arrastrar o hacer clic; lista los archivos y emite dv-change con files.

Calendario

<dv-calendar value="YYYY-MM-DD"> con nombres localizados (locale, por defecto el lang del documento), week-start y navegación con flechas (PgUp/PgDn cambian de mes). Opciones: min y max deshabilitan días, mode="range" selecciona un intervalo (value="inicio/fin") y months="2" muestra varios meses. Para un campo desplegable usa <dv-date-picker>.

Select personalizado

<dv-select> reemplaza al <select> nativo con listbox accesible (aria-activedescendant), teclado completo (↑ ↓ Home End Enter Esc, búsqueda al teclear) y panel posicionado automáticamente. Se declara con <option> y <optgroup>. Atributos: searchable, multiple, creatable, clearable, placeholder, required, disabled. Participa en <form> (FormData, reset, validación). Evento dv-change con { value, values }; setOptions([...]) carga opciones dinámicas.

Combobox / Autocomplete

<dv-combobox> (o <dv-select autocomplete>) es un campo de texto que filtra las opciones mientras escribes (sin distinguir acentos). Con creatable ofrece «Crear …» para añadir un valor nuevo. Si sales sin elegir, se restaura la selección anterior. Con multiple acumula varias opciones.

Selector de fecha

<dv-date-picker> muestra la fecha formateada con Intl y abre un calendario en un popover. Atributos: value (ISO), min, max, locale, week-start, date-style (short|medium|long|full), clearable, required. El valor enviado en el formulario es la fecha ISO (2026-10-14). Teclado en el calendario: flechas, PgUp/PgDn (mes) y con Shift (año).

Rango de fechas

Con el atributo range, <dv-date-picker> elige un intervalo: dos meses a la vez, vista previa del rango al mover el cursor y cierre automático al completarlo. El valor es un intervalo ISO 8601 inicio/fin; el evento dv-change trae { value, start, end }. El <dv-calendar> también acepta mode="range", months, min y max directamente.

Selector de hora

<dv-time-picker> ofrece columnas de hora y minutos (y AM/PM con hour12). Atributos: value (HH:MM), step (minutos entre opciones), min, max, clearable, required. El valor siempre se envía en 24 h. En el panel: ↑ ↓ cambian el valor, ← → cambian de columna, Enter confirma.

Campos dentro de un formulario

Los campos de esta sección (dv-select, dv-combobox, dv-date-picker, dv-time-picker) son form-associated: sus valores aparecen en new FormData(form), respetan required en la validación nativa, se restablecen con form.reset() y se deshabilitan con un <fieldset disabled>.

Slider y rango doble

<dv-slider> con uno o dos pulgares (range o value="20,80"); los pulgares no se cruzan y muestran su valor al arrastrar o enfocar. Atributos: min, max, step, prefix, suffix. Teclado: ← → (±paso), PgUp/PgDn (±10 pasos), Home/End. Eventos dv-input (en vivo) y dv-change (al soltar). En un formulario, el rango envía dos entradas con el mismo name.

Valoración (rating)

<dv-rating> es un único control role="slider": ← → cambian el valor, Home/End saltan a los extremos y Supr lo borra (con clearable). Atributos: max, value, half (medias estrellas), readonly, size="sm|lg".

Selector de color

<dv-color-picker> con área de saturación/brillo, tono, opacidad (alpha), campo hexadecimal, muestras (swatches="#f00,#0f0") y cuentagotas donde el navegador lo soporta. Valor #rrggbb (o #rrggbbaa con opacidad). Cada control se maneja con flechas (Shift = ×10). Eventos dv-input (al arrastrar) y dv-change.

Contraseña con medidor

<dv-password> añade a un <input> el botón mostrar/ocultar y, con meter, un medidor de seguridad (longitud mínima con min-length, mayúsculas y minúsculas, números y símbolos). El input real sigue dentro de tu formulario. Evento dv-change con { value, score } (0 a 4).

Textarea autoajustable y contador

Atributos sobre un <textarea class="dv-textarea">: data-dv-autosize crece con el contenido hasta data-max-rows filas (luego aparece scroll) y data-dv-count="#id" muestra la cuenta de caracteres, usando maxlength como tope.

Menciones (@)

<dv-mention> envuelve un <textarea> (o input) y ofrece usuarios al escribir @ (carácter configurable con trigger), en un panel junto al cursor. ↑ ↓ eligen, Enter o Tab insertan, Esc cierra. Las opciones se declaran con <option> o se asignan con element.users = [{ value, label, hint }]. Evento dv-mention.

Tarjetas de elección

CSS puro: un <label class="dv-choice-card"> con un dv-check (radio o checkbox) dentro. El estado marcado, el foco y el deshabilitado se reflejan en toda la tarjeta mediante :has().

Toggle group

<dv-toggle-group type="single|multiple"> agrupa botones con aria-pressed. En single volver a pulsar deselecciona (salvo con required); en multiple se combinan. ← → mueven el foco con tabulación itinerante. Evento dv-change.

Pestañas

<dv-tabs> enlaza data-tab con data-panel y añade los roles ARIA y la navegación con flechas.

Migas de pan

Lista ordenada con separadores automáticos; marca la página actual con aria-current="page".

Paginación

Enlaces o botones; la página activa usa aria-current="page".

Navegación lateral

Navegación vertical para app shells: dv-nav, dv-nav__label, dv-nav__item.

Pasos

Progreso por pasos: data-state="done" y aria-current="step".

Paleta de comandos

<dv-command hotkey="k"> crea un <dialog> nativo con búsqueda difusa, grupos (data-group), palabras clave (data-keywords) y evento dv-select. Ábrelo con data-dv-open="id" o ⌘K.

Barra de menús

<dv-menubar> es la barra de menús de una aplicación: cada elemento abre un menú; con uno abierto, pasar el cursor o pulsar ← → cambia de menú. Soporta submenús (.dv-menu__sub + data-submenu), ítems marcables (data-check + aria-checked), atajos con dv-kbd y deshabilitados. Teclado: ← → entre menús, ↓ ↑ entre ítems, → abre submenú, Esc cierra. Evento dv-select con { value, checked }.

Menú de navegación

<dv-nav-menu> es el menú de cabecera de un sitio: los paneles (.dv-bar__panel) llevan contenido libre (tarjetas, enlaces, imágenes) y se abren al pasar el cursor con retardo (hover-delay), al hacer clic o con ↓. Cambiar entre elementos con el panel abierto es inmediato. Esc cierra y devuelve el foco.

Alerta

Variantes --info, --success, --warning, --danger, --accent.

Banner

Barra de anuncio a ancho completo.

Toast

DevlUI.toast() apila notificaciones abajo a la derecha. Se pausan al pasar el ratón; duration: 0 las deja fijas; action añade un botón.

Progreso y medidor

<progress class="dv-progress"> nativo (sin value = indeterminado) y dv-meter por segmentos con --w y --c.

Spinner y skeleton

Estados de carga. Tamaño con --size (spinner) o --w/--h (skeleton).

Tooltip

Solo CSS: data-dv-tooltip="texto" y opcionalmente data-dv-placement="bottom". Aparece con hover y foco de teclado.

Diálogo

<dialog class="dv-dialog"> nativo: atrapa el foco y cierra con Esc. data-dv-open="id" lo abre, data-dv-close lo cierra, clic en el fondo también (desactívalo con data-dv-static).

Panel lateral

Variante lateral del diálogo: añade dv-dialog--drawer.

Popover

<dv-popover> usa la API nativa popover (capa superior, cierre con Esc y clic fuera). Se posiciona junto al disparador, se voltea si no cabe y sigue al scroll. Atributos: placement (top|bottom|left|right + -start|-end), offset, manual. Métodos open(), close(), toggle(); eventos dv-open y dv-close. Cualquier data-dv-close dentro del panel lo cierra.

Hover card

<dv-hovercard> muestra una vista previa al pasar el cursor o enfocar con el teclado, con retardos configurables (open-delay, close-delay). El panel sigue abierto mientras el cursor esté sobre él, y Esc lo cierra. Reutiliza .dv-popover__panel.

Menú contextual

<dv-context-menu> se abre con clic derecho, con la tecla de menú contextual (o Shift+F10) y con pulsación larga en pantallas táctiles. Se abre en el punto del cursor, navega con ↑ ↓ Home End y emite dv-select.

Diálogo de confirmación

DevlUI.confirm(opciones) abre un alertdialog modal y devuelve una Promise<boolean>. Esc o «Cancelar» resuelven false; el clic en el fondo no lo cierra. Con variant: "danger" el foco inicial queda en «Cancelar». Con cancelLabel: null funciona como alerta simple.

Sheet y drawer izquierdo

Variantes de <dialog class="dv-dialog">: dv-dialog--sheet (panel inferior, ideal en móvil; el asa .dv-sheet__handle se arrastra hacia abajo para cerrar) y dv-dialog--drawer dv-dialog--drawer-start (drawer por la izquierda).

Tarjeta

dv-card con __header, __body, __footer. --interactive añade elevación y spotlight que sigue al cursor.

Métrica y minigráfico

dv-stat para KPIs y <dv-sparkline values="…" fill> que dibuja un SVG con el color actual (cámbialo con color).

Insignia y punto

Estados compactos. dv-dot--pulse anima un indicador en vivo.

Avatar

Iniciales o imagen, tamaños --sm/--lg, --square, estado con data-status="online|busy|away" y grupos solapados.

Tabla

Tabla con hover y números tabulares (is-num). Con data-dv-sortable y th[data-sort="text|number"] se ordena por clic o teclado.

Lista

Filas con título, descripción y acciones al final (dv-list__end).

Línea de tiempo

Historial vertical; colorea cada nodo con --c.

Estado vacío

Estado vacío con icono, título, descripción y acción.

Acordeón

Basado en <details> nativo: accesible sin JS. Usa el mismo name en los details para que solo uno quede abierto.

Bloque de código

dv-code sobre <pre>; añade un botón de copiar con data-dv-copy.

Divisor

Separador con o sin etiqueta.

Utilidades de diseño

dv-stack (vertical), dv-row (horizontal con wrap) y dv-grid (auto-fit). Ajusta con --gap y --min; dv-spacer empuja elementos.

Collapsible

<dv-collapsible open> muestra u oculta contenido con altura animada. El disparador recibe aria-expanded y aria-controls; el contenido cerrado queda inert (no se enfoca ni se lee). Métodos toggle(), open(), close() y evento dv-toggle. A diferencia del acordeón, es un único bloque independiente.

Scroll area

<dv-scroll-area> da a una zona de altura fija una barra discreta y un degradado en los bordes que aún tienen contenido (expone data-top, data-bottom, data-left y data-right). El área es enfocable para desplazarla con el teclado. orientation="vertical|horizontal|both".

Paneles redimensionables

<dv-resizable> inserta separadores arrastrables entre paneles (.dv-resizable__panel) con tamaño inicial (data-size), mínimo y máximo (data-min, data-max, en %). Admite varios paneles y anidación (direction="vertical"). Teclado: flechas (Shift ×5), Home/End; doble clic restablece. Con storage-key recuerda los tamaños. Evento dv-resize.

Separator

<div class="dv-separator" role="separator"> (línea horizontal) y dv-separator--vertical para barras de herramientas. Es un separador puro, sin texto; para uno con etiqueta usa dv-divider.

Aspect ratio

.dv-aspect mantiene una proporción con la variable --ratio (por defecto 16 / 9). Los hijos img, video, iframe, svg o .dv-aspect__fill la rellenan.

Ejemplo de composición: card + fields + divider + botones.
