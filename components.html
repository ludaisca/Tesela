Tesela.

Componentes propios sin dependencias inspirados en el lenguaje visual de devl.dev: tokens en CSS, HTML semántico y Custom Elements en light DOM. Copia el HTML de cualquier demo, enlaza dos archivos y funciona en cualquier proyecto (estático, SSR o framework).

Instalación

Copia la carpeta lib/ a tu proyecto. El CSS funciona solo; el JS añade interactividad (Custom Elements y atributos data-tsl-*). Pon la clase tsl en <body> para heredar fuente y colores. Tema oscuro por defecto; data-theme="light" en <html> para claro.

<link rel="stylesheet" href="lib/tesela-ui.css" />
<script src="lib/tesela-ui.js" defer></script>

Temas y presets

Cada tema tiene dos modos (oscuro y claro) más system, que sigue al sistema operativo. Un preset cambia colores, radios y tipografías de una vez con <html data-preset="esmeralda"> (o en cualquier contenedor, y entonces solo afecta a su contenido). Todos cumplen las reglas de contraste de WCAG en ambos modos, y alto-contraste llega a AAA.

Contraste del tema activo

Se calcula en vivo con los colores reales del tema, el preset y el acento elegidos (WCAG 2.x: AA = 4,5:1 para texto, 3:1 para componentes y texto grande; AAA = 7:1).

Aplicar sin parpadeo

La biblioteca recuerda el tema, el preset y el acento en localStorage. Para que se apliquen antes del primer pintado, carga este script clásico en <head>, sin defer:

<script src="lib/theme-init.js"></script>

<!-- API -->
TeselaUI.setTheme("system");      // "dark" | "light" | "system"
TeselaUI.setPreset("medianoche"); // ver la lista de arriba
TeselaUI.setAccent("#10b981");    // elige solo un texto legible (blanco o casi negro)
TeselaUI.setAccent(null);         // vuelve al acento del preset

Tokens

Todo el estilo sale de variables --tsl-*. Sobrescríbelas después de cargar tesela-ui.css para adaptar la marca (o usa el panel lateral y "Copiar overrides CSS").

Tipografía

Mono por defecto, sans para titulares. Utilidades: tsl-eyebrow, tsl-heading, tsl-muted, tsl-kbd.

Botón

Variantes --primary, --accent, --subtle, --danger; tamaños --sm, --lg, --icon, --block, --pill. aria-busy="true" muestra un spinner.

Grupo de botones

Une botones adyacentes en un solo control.

Menú desplegable

<tsl-menu> con navegación por teclado (↑ ↓ Home End Esc), cierre al hacer clic fuera y evento tsl-select. align="end" lo alinea a la derecha.

Chip / interruptor

Chips de filtro. Con data-tsl-toggle alternan aria-pressed y emiten tsl-change.

Botón de copiar

data-tsl-copy="texto" copia un valor fijo; data-tsl-copy-target="#id" copia el contenido de otro elemento.

Input y campo

tsl-field agrupa tsl-label, control, tsl-hint y tsl-error. Usa aria-invalid="true" para el estado de error.

Grupo de inputs

Añade prefijos/sufijos con tsl-input-group__addon.

Select y textarea

Controles nativos con el estilo de la biblioteca.

Casilla y radio

<input type="checkbox|radio" class="tsl-check">, envuelto en tsl-choice para la etiqueta. Soporta indeterminate.

Grupo de radios

<tsl-radio-group> agrupa opciones button.tsl-radio con etiqueta y descripción. Tiene un solo punto de tabulación: las flechas mueven y seleccionan (respetando RTL y saltando las deshabilitadas), Espacio selecciona y Inicio/Fin saltan a los extremos. Participa en formularios (name, required, reset, fieldset disabled), con orientation="horizontal" y la variante .tsl-radio-group--cards. Evento tsl-change.

Interruptor

Checkbox nativo con role="switch": accesible y compatible con formularios.

Control deslizante

Relleno de color automático. data-tsl-output="#id" muestra el valor; data-tsl-suffix añade unidad.

Selector numérico

Botones con data-step="-1|1" que respetan min, max y step del input.

Control segmentado

<tsl-segmented value="…"> con role="radiogroup", flechas ← → y evento tsl-change.

Campo OTP

<tsl-otp length="6" name="code">: avance automático, retroceso, pegado y evento tsl-complete. mode="text" acepta letras.

Campo de etiquetas

<tsl-tags>: Enter o coma para añadir, Retroceso para borrar. Atributos value, name, max, placeholder.

Zona de carga

<tsl-dropzone accept multiple name>: arrastrar o hacer clic; lista los archivos y emite tsl-change con files.

Calendario

<tsl-calendar value="YYYY-MM-DD"> con nombres localizados (locale, por defecto el lang del documento), week-start y navegación con flechas (PgUp/PgDn cambian de mes). Opciones: min y max deshabilitan días, mode="range" selecciona un intervalo (value="inicio/fin") y months="2" muestra varios meses. Para un campo desplegable usa <tsl-date-picker>.

Select personalizado

<tsl-select> reemplaza al <select> nativo con listbox accesible (aria-activedescendant), teclado completo (↑ ↓ Home End Enter Esc, búsqueda al teclear) y panel posicionado automáticamente. Se declara con <option> y <optgroup>. Atributos: searchable, multiple, creatable, clearable, placeholder, required, disabled. Participa en <form> (FormData, reset, validación). Evento tsl-change con { value, values }; setOptions([...]) carga opciones dinámicas.

Combobox / Autocomplete

<tsl-combobox> (o <tsl-select autocomplete>) es un campo de texto que filtra las opciones mientras escribes (sin distinguir acentos). Con creatable ofrece «Crear …» para añadir un valor nuevo. Si sales sin elegir, se restaura la selección anterior. Con multiple acumula varias opciones.

Selector de fecha

<tsl-date-picker> muestra la fecha formateada con Intl y abre un calendario en un popover. Atributos: value (ISO), min, max, locale, week-start, date-style (short|medium|long|full), clearable, required. El valor enviado en el formulario es la fecha ISO (2026-10-14). Teclado en el calendario: flechas, PgUp/PgDn (mes) y con Shift (año).

Rango de fechas

Con el atributo range, <tsl-date-picker> elige un intervalo: dos meses a la vez, vista previa del rango al mover el cursor y cierre automático al completarlo. El valor es un intervalo ISO 8601 inicio/fin; el evento tsl-change trae { value, start, end }. El <tsl-calendar> también acepta mode="range", months, min y max directamente.

Selector de hora

<tsl-time-picker> ofrece columnas de hora y minutos (y AM/PM con hour12). Atributos: value (HH:MM), step (minutos entre opciones), min, max, clearable, required. El valor siempre se envía en 24 h. En el panel: ↑ ↓ cambian el valor, ← → cambian de columna, Enter confirma.

Campos dentro de un formulario

Los campos de esta sección (tsl-select, tsl-combobox, tsl-date-picker, tsl-time-picker) son form-associated: sus valores aparecen en new FormData(form), respetan required en la validación nativa, se restablecen con form.reset() y se deshabilitan con un <fieldset disabled>.

Slider y rango doble

<tsl-slider> con uno o dos pulgares (range o value="20,80"); los pulgares no se cruzan y muestran su valor al arrastrar o enfocar. Atributos: min, max, step, prefix, suffix. Teclado: ← → (±paso), PgUp/PgDn (±10 pasos), Home/End. Eventos tsl-input (en vivo) y tsl-change (al soltar). En un formulario, el rango envía dos entradas con el mismo name.

Valoración (rating)

<tsl-rating> es un único control role="slider": ← → cambian el valor, Home/End saltan a los extremos y Supr lo borra (con clearable). Atributos: max, value, half (medias estrellas), readonly, size="sm|lg".

Selector de color

<tsl-color-picker> con área de saturación/brillo, tono, opacidad (alpha), campo hexadecimal, muestras (swatches="#f00,#0f0") y cuentagotas donde el navegador lo soporta. Valor #rrggbb (o #rrggbbaa con opacidad). Cada control se maneja con flechas (Shift = ×10). Eventos tsl-input (al arrastrar) y tsl-change.

Contraseña con medidor

<tsl-password> añade a un <input> el botón mostrar/ocultar y, con meter, un medidor de seguridad (longitud mínima con min-length, mayúsculas y minúsculas, números y símbolos). El input real sigue dentro de tu formulario. Evento tsl-change con { value, score } (0 a 4).

Textarea autoajustable y contador

Atributos sobre un <textarea class="tsl-textarea">: data-tsl-autosize crece con el contenido hasta data-max-rows filas (luego aparece scroll) y data-tsl-count="#id" muestra la cuenta de caracteres, usando maxlength como tope.

Menciones (@)

<tsl-mention> envuelve un <textarea> (o input) y ofrece usuarios al escribir @ (carácter configurable con trigger), en un panel junto al cursor. ↑ ↓ eligen, Enter o Tab insertan, Esc cierra. Las opciones se declaran con <option> o se asignan con element.users = [{ value, label, hint }]. Evento tsl-mention.

Tarjetas de elección

CSS puro: un <label class="tsl-choice-card"> con un tsl-check (radio o checkbox) dentro. El estado marcado, el foco y el deshabilitado se reflejan en toda la tarjeta mediante :has().

Toggle group

<tsl-toggle-group type="single|multiple"> agrupa botones con aria-pressed. En single volver a pulsar deselecciona (salvo con required); en multiple se combinan. ← → mueven el foco con tabulación itinerante. Evento tsl-change.

Pestañas

<tsl-tabs> enlaza data-tab con data-panel y añade los roles ARIA y la navegación con flechas.

Migas de pan

Lista ordenada con separadores automáticos; marca la página actual con aria-current="page".

Paginación

Enlaces o botones; la página activa usa aria-current="page".

Navegación lateral

Navegación vertical para app shells: tsl-nav, tsl-nav__label, tsl-nav__item.

Pasos

Progreso por pasos: data-state="done" y aria-current="step".

Paleta de comandos

<tsl-command hotkey="k"> crea un <dialog> nativo con búsqueda difusa, grupos (data-group), palabras clave (data-keywords) y evento tsl-select. Ábrelo con data-tsl-open="id" o ⌘K.

Barra de menús

<tsl-menubar> es la barra de menús de una aplicación: cada elemento abre un menú; con uno abierto, pasar el cursor o pulsar ← → cambia de menú. Soporta submenús (.tsl-menu__sub + data-submenu), ítems marcables (data-check + aria-checked), atajos con tsl-kbd y deshabilitados. Teclado: ← → entre menús, ↓ ↑ entre ítems, → abre submenú, Esc cierra. Evento tsl-select con { value, checked }.

Menú de navegación

<tsl-nav-menu> es el menú de cabecera de un sitio: los paneles (.tsl-bar__panel) llevan contenido libre (tarjetas, enlaces, imágenes) y se abren al pasar el cursor con retardo (hover-delay), al hacer clic o con ↓. Cambiar entre elementos con el panel abierto es inmediato. Esc cierra y devuelve el foco.

Barra lateral

<tsl-sidebar> va dentro de .tsl-sidebar-layout junto a .tsl-sidebar-inset. Con collapsible="icon" se contrae a una columna de iconos (el nombre pasa a title); con offcanvas desaparece. Cuando el contenedor mide menos de breakpoint (720 px) se convierte en un cajón con fondo, Esc y devolución del foco. Cualquier [data-tsl-sidebar-toggle] la alterna sin código, shortcut="b" añade Ctrl/⌘+B y storage-key recuerda el estado. Submenús con un botón aria-expanded seguido de .tsl-sidebar__sub. Evento tsl-toggle.

Alerta

Variantes --info, --success, --warning, --danger, --accent.

Banner

Barra de anuncio a ancho completo.

Toast

TeselaUI.toast() apila notificaciones abajo a la derecha. Se pausan al pasar el ratón; duration: 0 las deja fijas; action añade un botón.

Progreso y medidor

<progress class="tsl-progress"> nativo (sin value = indeterminado) y tsl-meter por segmentos con --w y --c.

Spinner y skeleton

Estados de carga. Tamaño con --size (spinner) o --w/--h (skeleton).

Tooltip

Solo CSS: data-tsl-tooltip="texto" y opcionalmente data-tsl-placement="bottom". Aparece con hover y foco de teclado.

Diálogo

<dialog class="tsl-dialog"> nativo: atrapa el foco y cierra con Esc. data-tsl-open="id" lo abre, data-tsl-close lo cierra, clic en el fondo también (desactívalo con data-tsl-static).

Panel lateral

Variante lateral del diálogo: añade tsl-dialog--drawer.

Popover

<tsl-popover> usa la API nativa popover (capa superior, cierre con Esc y clic fuera). Se posiciona junto al disparador, se voltea si no cabe y sigue al scroll. Atributos: placement (top|bottom|left|right + -start|-end), offset, manual. Métodos open(), close(), toggle(); eventos tsl-open y tsl-close. Cualquier data-tsl-close dentro del panel lo cierra.

Hover card

<tsl-hovercard> muestra una vista previa al pasar el cursor o enfocar con el teclado, con retardos configurables (open-delay, close-delay). El panel sigue abierto mientras el cursor esté sobre él, y Esc lo cierra. Reutiliza .tsl-popover__panel.

Menú contextual

<tsl-context-menu> se abre con clic derecho, con la tecla de menú contextual (o Shift+F10) y con pulsación larga en pantallas táctiles. Se abre en el punto del cursor, navega con ↑ ↓ Home End y emite tsl-select.

Diálogo de confirmación

TeselaUI.confirm(opciones) abre un alertdialog modal y devuelve una Promise<boolean>. Esc o «Cancelar» resuelven false; el clic en el fondo no lo cierra. Con variant: "danger" el foco inicial queda en «Cancelar». Con cancelLabel: null funciona como alerta simple.

Sheet y drawer izquierdo

Variantes de <dialog class="tsl-dialog">: tsl-dialog--sheet (panel inferior, ideal en móvil; el asa .tsl-sheet__handle se arrastra hacia abajo para cerrar) y tsl-dialog--drawer tsl-dialog--drawer-start (drawer por la izquierda).

Tarjeta

tsl-card con __header, __body, __footer. --interactive añade elevación y spotlight que sigue al cursor.

Métrica y minigráfico

tsl-stat para KPIs y <tsl-sparkline values="…" fill> que dibuja un SVG con el color actual (cámbialo con color).

Insignia y punto

Estados compactos. tsl-dot--pulse anima un indicador en vivo.

Avatar

Iniciales o imagen, tamaños --sm/--lg, --square, estado con data-status="online|busy|away" y grupos solapados.

Tabla

Tabla con hover y números tabulares (is-num). Con data-tsl-sortable y th[data-sort="text|number"] se ordena por clic o teclado.

Lista

Filas con título, descripción y acciones al final (tsl-list__end).

Línea de tiempo

Historial vertical; colorea cada nodo con --c.

Estado vacío

Estado vacío con icono, título, descripción y acción.

Acordeón

Basado en <details> nativo: accesible sin JS. Usa el mismo name en los details para que solo uno quede abierto.

Bloque de código

tsl-code sobre <pre>; añade un botón de copiar con data-tsl-copy.

Divisor

Separador con o sin etiqueta.

Tree view

<tsl-tree> convierte una lista anidada <ul> en un árbol accesible (role="tree", aria-expanded, aria-level). Teclado: ↑ ↓ navegan, → expande o entra, ← colapsa o sube, Inicio/Fin, Enter selecciona, * expande los hermanos y las letras saltan por nombre. Con checkable cada nodo tiene casilla, con estado mixto en los padres (Espacio marca). Atributos de nodo: data-value, data-expanded, data-selected. Eventos tsl-select, tsl-toggle y tsl-check.

Lista virtualizada

<tsl-virtual-list> solo dibuja las filas visibles: con 10 000 elementos el DOM tiene unas docenas de nodos. Asigna list.items (cualquier arreglo) y, si quieres un diseño propio, list.renderItem = (item, i) => Node. Con selectable es un listbox navegable (↑ ↓ PgUp PgDn Inicio Fin, Enter) y emite tsl-select. Alto de fila fijo (item-height); scrollToIndex(i, "center") desplaza hasta un elemento.

Listas ordenables

<tsl-sortable> reordena con el puntero y con el teclado. Con handle=".tsl-sortable__handle" solo el asa arrastra (recomendado en pantallas táctiles). Teclado: Espacio toma el elemento, ↑ ↓ lo mueven, Espacio lo suelta y Esc cancela; cada paso se anuncia por una región aria-live. direction="vertical|horizontal|grid". Las listas con el mismo group intercambian elementos. Evento tsl-sort con { item, from, to }.

Kanban

Un tablero es un conjunto de <tsl-sortable> con el mismo group, dentro de .tsl-kanban / .tsl-kanban__col. Las tarjetas se arrastran entre columnas (con autoscroll) y con el teclado: Espacio toma, ↑ ↓ reordenan, ← → cambian de columna, Espacio suelta. Cada cambio de columna se anuncia con su nombre (label) y emite tsl-sort en la columna de destino.

Tabla de datos

<tsl-data-table> reúne búsqueda, orden (clic en la cabecera: ascendente → descendente → sin orden), selección con casillas (Shift para rangos), columnas visibles, densidad, paginación con tamaño de página y exportación CSV. Se configura con table.columns (key, label, sort, align, format, render) y table.rows; también acepta un <table> HTML normal dentro. Atributos: page-size, selectable, searchable, exportable, height (cabecera fija), density y loading. Eventos tsl-sort, tsl-page, tsl-selection y tsl-row-click.

Gráfica de líneas y áreas

<tsl-chart type="line|area"> dibuja series SVG con rejilla, leyenda interactiva (clic para ocultar una serie), tooltip y cursor al pasar el puntero. Datos: chart.data = { labels, series: [{ name, values }] } (o el atributo data en JSON). Opciones: smooth, prefix, suffix, height. Es accesible: el elemento recibe el foco, ← → recorren los puntos, el valor se anuncia en una región aria-live y hay una tabla de datos para lectores de pantalla. Los colores salen de --tsl-chart-1…8.

Gráfica de barras

<tsl-chart type="bar"> con barras agrupadas por defecto, stacked para apiladas y horizontal para barras horizontales (útil con etiquetas largas). Admite valores negativos.

Dona y gauge

type="donut" reparte segmentos (data = { segments: [{ label, value }] }); al pasar el cursor el centro muestra el segmento y su porcentaje, y la leyenda oculta segmentos. type="gauge" muestra un valor dentro de un rango (data = { value, min, max, label, thresholds: [{ to, color }] }), coloreado según el umbral.

Mapa de calor

type="heatmap" pinta una matriz (data = { rows, cols, values }) con la intensidad del color según el valor. Las celdas vacías (null) se dibujan con borde punteado. Con el teclado, las cuatro flechas recorren las celdas.

Utilidades de diseño

tsl-stack (vertical), tsl-row (horizontal con wrap) y tsl-grid (auto-fit). Ajusta con --gap y --min; tsl-spacer empuja elementos.

Collapsible

<tsl-collapsible open> muestra u oculta contenido con altura animada. El disparador recibe aria-expanded y aria-controls; el contenido cerrado queda inert (no se enfoca ni se lee). Métodos toggle(), open(), close() y evento tsl-toggle. A diferencia del acordeón, es un único bloque independiente.

Scroll area

<tsl-scroll-area> da a una zona de altura fija una barra discreta y un degradado en los bordes que aún tienen contenido (expone data-top, data-bottom, data-left y data-right). El área es enfocable para desplazarla con el teclado. orientation="vertical|horizontal|both".

Paneles redimensionables

<tsl-resizable> inserta separadores arrastrables entre paneles (.tsl-resizable__panel) con tamaño inicial (data-size), mínimo y máximo (data-min, data-max, en %). Admite varios paneles y anidación (direction="vertical"). Teclado: flechas (Shift ×5), Home/End; doble clic restablece. Con storage-key recuerda los tamaños. Evento tsl-resize.

Separator

<div class="tsl-separator" role="separator"> (línea horizontal) y tsl-separator--vertical para barras de herramientas. Es un separador puro, sin texto; para uno con etiqueta usa tsl-divider.

Aspect ratio

.tsl-aspect mantiene una proporción con la variable --ratio (por defecto 16 / 9). Los hijos img, video, iframe, svg o .tsl-aspect__fill la rellenan.

Inicio de sesión

Ejemplo de composición: card + fields + divider + botones.

Panel de ajustes

Tabs + lista + switches + acciones.
